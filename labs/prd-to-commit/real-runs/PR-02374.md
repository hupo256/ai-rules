## 4. 偏离 skill / 工具问题

1. **fetch-prd 漏附件**：PRD 里 `<figure view-type="Preview"><source token>` 的 HTML 原型（「以二期原型为准」）没下载，也没进 `meta.unexpanded`。候选：fetch-prd 识别 figure/source 附件并下载到 `inputs/`，或至少列入 unexpanded。
2. **MSW 未加**（偏离 §5「自行决定加 MSW」）：二期 10+ 接口全占位，选择用浏览器 spec mocks 验证。
3. **macOS 无 `timeout`**：主会话两次 `timeout ... tsc` 实际没执行，输出为空被误读为通过，直到 check.mjs 才发现。
4. **stats.mjs 拆不出同会话多需求**：匹配只看前 5 条用户消息/cwd。候选：允许 `--since/--until` 或按 `~/.prd-cache/<ID>` 路径出现区间切分。
5. **run-log 估计时间**第 2 次出现（PR-02418 也有）→ 已满足「2 次」门槛，候选规则：run-log 时间一律 `date`。
6. **子 agent 自报的「范围 tsc 0 错」不可信**：7 个编码子 agent 都用临时 tsconfig 自查，合并后 check 仍抓到 2 个错误；浏览器抓到 2 个白屏。
7. **大需求的清单粒度**：PRD 一句话含多个可验收动作（「复制、删除和拖拽排序」）时，清单一行、子 agent 实现一半，冷读才补出。候选（§2）：清单按「动作」拆行，不按句子。
8. **i18n 草稿文件**（新做法）：并行子 agent 不直接改同一语言文件，各写草稿由主会话合并——0 冲突，可沉淀进 §3.5。
9. **存量 bug 暴露**：admin `RichTextEditor`（react-quill）在 React 19 下本就挂载即崩，平台内容编辑页同样受影响；本次绕开未修。
